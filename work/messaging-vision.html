The problem

A tool that fought the people who relied on it.

A heuristic evaluation and user testing revealed the builder was failing the people who relied on it most. The interface leaned on a legacy pattern that didn’t match how users actually think — they reason channel-first, the tool didn’t. And like many legacy tools, it had been built by engineers, so the UX was inconsistent and all over the place — optimized for the system’s structure, not the user’s.

Engineer-built legacy UI

Outdated interactions, inconsistent patterns, and heavy reliance on external documentation.

Mental-model mismatch

Users think channel-first; the backend is channel-agnostic — a fundamental gap.

Trial-and-error

People weren’t sure how a component would behave, so they hesitated and clicked around.

Grounding it in evidence

I made the pain undeniable first.

In my moderated study of the existing tool, task success was near-zero without intervention — which is exactly what made the case for a redesign. A 10-point Nielsen heuristic audit turned scattered complaints into a prioritized, defensible list.

The vision

A Generative AI Workspace.

Rather than patch the old UI, I made the case for a redesign built on a “Tell me + Tweak it” model: the AI gets you ~80% of the way from a plain-language prompt, then you refine with full control. Three principles anchored it.

01

Channel-specific

The interface reflects the user’s channel-first mental model — you say where it’s going, and the UI adapts.

02

Simple system

Let the system handle complexity. Keep navigation simple, flexible, and predictable.

03

Consumer-grade

Modern UX best practices — a clean UI, a live preview, and contextual guidance instead of a manual.

The key trade-off

AI as the translator between user and system.

The current system was built by engineers around a channel-agnostic backend — and engineering wasn’t open to changing that architecture. But users think channel-first. Instead of fighting either side, I designed a concept that respects both. That’s why AI became load-bearing: it does the translation between the user’s intent and the system’s structure — unlocking the vision without an architectural rewrite.
